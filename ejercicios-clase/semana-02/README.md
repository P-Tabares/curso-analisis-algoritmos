## Entorno virtual

Desde la raíz del proyecto, crear el entorno con `python -m venv venv`.
En Windows PowerShell, activarlo con `venv\Scripts\Activate.ps1`.
En Git Bash, activarlo con `source venv/Scripts/activate`.
Instalar las dependencias fijadas con `python -m pip install -r requirements.txt`.
Así, otra persona puede reproducir el entorno usando el mismo `requirements.txt`.
Para ejecutar el clasificador, ejecutar `python ejercicios-clase/semana-02/clasificador_anios.py`.
